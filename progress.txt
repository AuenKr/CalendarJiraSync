## Codebase Patterns
- **Build Process**: Uses a split build strategy. Main extension parts (popup, background) use CRXJS. Content script uses a separate `vite.content.config.ts` to generate a single IIFE bundle without loaders/dynamic imports to satisfy CSP.
- **Manifest Patching**: `scripts/patch-manifest.js` is used to merge the content script into the manifest after the split build.
- **Trusted Types**: All DOM injections in content scripts must use the `jira-sync-policy` Trusted Types policy.
- **Jira API**: `src/lib/jira.ts` provides helper functions that delegate to the background script via messaging. Direct API calls happen only in the background script.
- **Dependencies**: 
  - Use Zod v3 to avoid `new Function` usage.
  - Use Preact instead of React to avoid `innerHTML = "<script>"` usage and reduce bundle size.
