
## 2026-01-27 - Fix Suggestion Box Behavior
Thread: https://ampcode.com/threads/$AMP_CURRENT_THREAD_ID
- **Bug Fix**: The suggestion box now closes when the event title input loses focus.
- **Implementation**:
  - Added `isFocused` state to `ContentApp.tsx` to track focus on the title input.
  - Added `focus` and `blur` event listeners to update `isFocused`.
  - Updated the `useEffect` controlling the popover visibility to respect `isFocused`.
  - Added `onMouseDown={(e) => e.preventDefault()}` to `PopoverContent` to prevent focus loss when interacting with the popover itself (though the main fix is the focus tracking).
- **Verification**: Verified that the suggestion box closes when clicking outside the input field.
